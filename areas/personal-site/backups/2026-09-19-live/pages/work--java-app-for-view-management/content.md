## Visible text

<  Java app for view management

This Java application allows you to keep the views of an app in order, by merging the images of the app screens inserted in a dedicated folder, with the Emaster.xlsx file containing the information on them, thus creating an Excel file for each screen.

I created this application because I needed to organize the BackPic views and I thought this was a good way to make order, to have an opportunity to apply what I learned about the software architecture, make practice with Java and because at that moment I needed to think of something else as the Covid-19 epidemic has just begun.

Below I insert some screenshots and the file, but if you have difficulties do not hesitate to contact me.

Ps: it works, and it's definitely better than the code written for HereGone, but it's not a super polished version.
