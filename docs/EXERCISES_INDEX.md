# Esercizi Index

> Sistema semplice per tracciare esercizi da creare.
> Quando ricevi una pagina del libro, aggiorna questo file.

---

## Come Aggiungere Esercizi

1. Quando ricevi una foto/immagine di una pagina del libro:
   - Leggi gli esercizi presenti
   - Aggiungi una sezione qui sotto con l'unità e la pagina
   - Lista gli esercizi da fare

2. Quando completi un esercizio:
   - Metti ✅ accanto all'esercizio
   - Indica il nome del file creato
